# UFit iOS Sample

Projet SwiftUI minimal pour préparer l'environnement iOS de l'application UFit.

## Ouvrir dans Xcode

Ouvrir `UFit.xcodeproj`, sélectionner un simulateur iOS, puis lancer le schéma `UFit`.

## Structure

- `UFit/UFitApp.swift` : point d'entrée SwiftUI.
- `UFit/Views/LoginView.swift` : page de connexion blanche et minimale.
- `UFit/Assets.xcassets` : couleur d'accent de base.
